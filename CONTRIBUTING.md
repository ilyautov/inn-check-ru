# Как помочь проекту

Спасибо, что заглянули. Самая ценная помощь — не код, а **факты**:

1. **Расхождение с реестром.** Прогнали свой ИНН и цифра не сошлась с egrul.nalog.ru / ГИР БО / ФССП? Заведите issue с ИНН, датой прогона и скриншотом официального источника. Это баг первого приоритета.
2. **Новый источник.** Нашли открытый реестр или агрегатор, которого нет в каскаде (особенно без капчи и без ключа) — issue или PR с правкой таблицы источников в SKILL.md.
3. **Пороги светофора.** Есть кейс, где порог сработал неверно (🟢 на проблемном контрагенте или 🔴 на нормальном) — расскажите в issue, обсудим настройку.

## Правила

- **Числа — кодом.** Любая новая логика подсчёта (скоринг, пороги, агрегация) идёт в `scripts/`, а не в прозу SKILL.md.
- **Ничего не выдумываем.** Если источник недоступен — «не проверено», а не заглушка. PR, добавляющий данные без источника, не будет принят.
- **Без обхода капч.** Источники с капчей — только ручная опция для пользователя.

## Технический цикл

```bash
ruff check scripts/
python3 -c "import yaml, pathlib; yaml.safe_load(pathlib.Path('SKILL.md').read_text().split('---')[1])"
```

Оба прогона должны быть зелёными — то же самое делает CI на каждый PR.

## Issues

Метки: `registry-mismatch` (расхождение с реестром), `new-source` (новый источник), `threshold` (пороги), `good first issue` (для первых PR).
