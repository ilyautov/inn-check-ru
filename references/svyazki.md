# Связки: скрипты и инструменты скилла

Вынесено из SKILL.md (потолок размера скилла). Читать, когда нужно понять, какой скрипт что делает.

- `scripts/fetch_counterparty.py` — сбор зелёной зоны ФНС (ЕГРЮЛ/ЕГРИП / Прозрачный бизнес / ГИР БО + ✅ Реестр МСП, НПД, ЕРКНМ/РНП по кэшу, спецреестры service.nalog.ru — не верифицированы); разводит ИП/ООО по длине ИНН; `--save` — снимок для мониторинга.
- `scripts/fin_scoring.py` — финансовый профиль кодом из строк ГИР БО (пороги в разделе «Финансовый профиль кодом»; для ИП неприменим — нет публичной отчётности).
- `scripts/profiles.py` + `data/profiles_ru.json` — профили цели (нейтрально / отсрочка / предоплата / подрядчик / доля / клиент_115фз / самопроверка / ндс_вычет): единый каталог сигналов, deal-killers и рекомендации по профилю, светофор кодом (шаги 1 и 5); `--list` — таблица профилей.
- `scripts/sanctions_check.py` — офлайн-сверка с перечнями РФМ + OFAC SDN + EU Consolidated (кэш в `~/.cache/inn-check-ru/`).
- `scripts/batch_check.py` — батч по CSV/списку ИНН: светофор профиля на каждого, сортировка «опасное наверх».
- `scripts/extract_inn.py` — извлечение ИНН из входящего документа (текст, CSV/TSV, HTML, JSON, DOCX; PDF честно не поддерживается): отбраковка мусора контрольным числом ФНС, пометка «новый / уже проверялся», `--проверить` — новые сразу в `batch_check.py --режим quick` (раздел «Проверка без запроса»).
- `scripts/watchlist.py` — список наблюдения, прогон по расписанию, тихий режим для крона.
- `scripts/retro_verdict.py` — вердикт на дату в прошлом по снимку, сохранённому тогда (`--дата ГГГГ-ММ-ДД`, `--список`). Снимок новее даты не берётся, сеть не трогается: должная осмотрительность доказывается тем, что было видно ДО сделки.
- `scripts/dossier.py` — досье должной осмотрительности (Markdown/DOCX) на дату проверки: что проверено, что НЕ проверено и почему, критерии выбора контрагента из письма ФНС БВ-4-7/3060@ (деловая репутация, возможность исполнения, платёжеспособность) с покрытием источниками и ручным добором.
- `scripts/evidence_pack.py` — пакет доказательств: `fetch_counterparty.py <ИНН> --пакет <каталог>` сохраняет сырые ответы источников байт в байт с манифестом SHA-256; `INN_CHECK_TSA=да` — ещё и штамп времени RFC 3161 (на TSA уходит только хеш). `--проверить <каталог>` пересчитывает хеши; `dossier.py --пакет <каталог>` печатает целостность в досье. Предлагай пакет, когда проверка нужна «для налоговой» или перед крупной сделкой. Без штампа хеши доказывают лишь согласованность (владелец мог их пересчитать) — для спора нужен штамп; штамп публичного TSA — не квалифицированная метка по 63-ФЗ; ответы источниками не подписаны. Так и говори.
- `scripts/domain_check.py` — домен контрагента по WHOIS реестра .ru/.su/.рф: тип регистранта (организация / частное лицо, без имени), дата регистрации, срок оплаты, делегирован ли; `--дата-регистрации` из ЕГРЮЛ — насколько домен моложе компании. ИНН и название организации реестр не раскрывает: принадлежность домена компании не подтверждается.
- `scripts/snapshot.py` — отпечаток проверки для мониторинга (вместо полного слепка).
- `scripts/check_access.py` — probe доступности источников с текущей сети (`--прокси`); `scripts/install_ca.py` — корень УЦ Минцифры; `scripts/proxy.py` — разбор настройки прокси (`--прокси` > `INN_CHECK_PROXY` > `HTTPS_PROXY`), общий для обоих.
- `scripts/registries_refresh.py` — офлайн-сверка по дампам ЕРКНМ (плановые проверки) и РНП.
- `scripts/disq_dump.py` — реестр дисквалифицированных лиц из еженедельной CSV-выгрузки ФНС: `--refresh` строит индекс (ФИО — только HMAC), сверка по ФИО руководителя из ЕГРЮЛ и по ИНН организации; блок `дисквалифицированные`, сигнал `дисквалификация_руководителя`.
- `scripts/rospatent_tz.py` — товарные знаки по ИНН правообладателя из открытого реестра Роспатента: `--refresh` потоком разбирает CSV (~700 МБ, на диск не пишется) в индекс; блок `товарные_знаки`.
- `scripts/cbr_registries.py` — госреестры ЦБ (МФО, КПК, СКПК, ломбарды; лицензии профучастников рынка ценных бумаг и аннулированные с причиной; инвестсоветники; БКИ; СРО и их члены) из XLSX со страниц cbr.ru/microfinance/registry, cbr.ru/registries/rcb и cbr.ru/registries: `--refresh` строит индекс по ИНН (без ФИО и контактов), статус «действует / исключена» с датами; блок `реестры_цб`.
- `scripts/rzn_licenses.py` — лицензии Росздравнадзора (фармацевтика, наркотики, медизделия) из еженедельных XML открытых данных: `--refresh` строит индекс по ИНН, сверка локальная; блок `лицензии_рзн`.
- `scripts/opendata_refresh.py` + `scripts/opendata_index.py` — дампы открытых данных ФНС: скачивание с докачкой и проверкой целостности, затем локальный индекс по ИНН (`--построить`, `--найти <ИНН>`). Даёт офлайн среднесписочную численность, применяемые спецрежимы, уплаченные налоги, недоимку с пенями и штрафами (`debtam`, квартальная; при сумме > 0 поднимает сигнал `налоговая_задолженность` с суммой и датой выгрузки) и штрафы за налоговые правонарушения (`taxoffence`, годовая) — то, что сидит за детальным эндпоинтом «Прозрачного бизнеса» и с не-РФ IP недоступно. Сведения ДАТИРОВАНЫ выгрузкой, и дата едет вместе со значением; блок сбора — `дампы_фнс`.
- `scripts/diff_counterparty.py` — мониторинг: diff двух последних снимков, leading indicators с датами «было/стало».
- `scripts/affiliates_graph.py` + `scripts/droblenie_check.py` — граф связей (checko API, ленивый обход: `--глубина`, `--бюджет`, `--без-стопа`, `--известные`) и чеклист признаков дробления кодом; пороги из `data/canon_ru.json`.
- **MCP-обёртка в `mcp/`** — те же скрипты как read-only инструменты MCP-сессии, для сценариев, где проверка — инструмент в цепочке (напр. связка с diadoc-mcp-ru: счёт → `counterparty_fetch` до подписи). Данные с tier-маркерами отдаются как есть; методология светофора — здесь, в SKILL.md.
- Полный набор бизнес-скиллов (налоги, дебиторка, CRM): [small-business-ru](https://github.com/ilyautov/small-business-ru). Этот репозиторий — самостоятельная версия самого востребованного скилла оттуда.
