# Возможности каналов и границы настройки

Читать перед выбором канала установки, переносом конфигурации или заявлением о совместимости. Машинный источник — [data/workflow_capabilities.json](../data/workflow_capabilities.json), schema 1, версия 1.13.0, статус `unpublished`. Матрица описывает заявленные поверхности настройки, а не принятую пользователем установку.

| Канал | Workflow | Ключи Checko/DaData | Прокси | Runs/events/policy/OCR executable | PDF по умолчанию |
|---|---|---|---|---|---|
| CLI | полный | окружение хоста | окружение хоста | окружение хоста | extra + локальные бинарники |
| Plain MCP | полный workflow; document принимает текст/управляемые форматы | окружение хоста | окружение хоста | окружение хоста | публичного PDF-входа нет; локальный PDF через CLI |
| Codex/Cursor skill / release ZIP | через локальный движок | окружение хоста | окружение хоста | окружение хоста | extra + локальные бинарники |
| Docker | полный | окружение контейнера | окружение контейнера | env; пути и бинарники должны быть доступны в контейнере, каталоги смонтированы с записью | не поддержан стандартным образом |
| Claude plugin | полный MCP | объявленные поля plugin userConfig | поле не объявлено | поля не объявлены | не поддержан стандартным артефактом |
| MCPB | полный MCP | объявленные поля MCPB userConfig | объявленное поле | поля не объявлены | не поддержан стандартным артефактом |
| Browser extension | только native manual handoff | не поддержаны этим каналом | не поддержан этим каналом | окружение native host | не поддержан стандартным артефактом |

Ни один текущий MCP-канал не предоставляет загрузчик PDF или произвольный путь к файлу. Наличие extra/настроенных OCR-бинарников в doctor не создаёт такого входа; локальный PDF обрабатывает CLI.

У plugin/MCPB нет гарантированного наследования произвольного окружения; отсутствие поля нельзя описывать как «впишите env и всё заработает». Для управляемого run root, policy и OCR используйте plain MCP/CLI с конфигурацией процесса либо отдельно подтверждённый путь хоста. Ключи не передаются аргументами инструмента или текстом документа.

| Назначение | Переменная |
|---|---|
| Checko / DaData | `CHECKO_API_KEY` / `DADATA_API_KEY` |
| Своя нода | `INN_CHECK_PROXY` |
| Хранилище проверок | `INN_CHECK_RUNS_DIR` |
| Очередь событий | `INN_CHECK_EVENTS_DIR` |
| Политика провайдеров | `INN_CHECK_PROVIDER_POLICY` |
| Poppler / Tesseract | `INN_CHECK_PDF_RENDERER` / `INN_CHECK_TESSERACT` |

Руты, policy-файл, executables и сеть принадлежат оператору. Новые MCP-инструменты принимают идентификаторы, не произвольные пути. Extension должен читать то же хранилище, что CLI/MCP; его `host.json` не меняет run root. Большие отчёты передаются расширению проекцией привязки; полный JSON остаётся в CLI/MCP.

Ядро Python >=3.10 использует stdlib, обязательных dependencies нет. Опциональный MCP SDK `>=1.30,<2`, PDF `pypdf>=6.21,<7`; OCR не облачный и требует абсолютных настроенных путей и `rus+eng`. Проект не устанавливает OCR-бинарники автоматически. [Документы](document-input.md).

MCP содержит **33** инструмента: 14 прежних, 15 workflow/events/diagnostics и 4 document/select/compare/replay. [Полный список и эффекты](../mcp/README.md). CLI дополнительно даёт cache update, watch plan/monitor, events retry и локальные metrics; эти команды не подразумевают одноимённый MCP-инструмент.

Read/resume/render/status/plan/compare/replay не собирают данные из сети и не пишут долговременное состояние. Start и refresh делают сетевой сбор и запись; manual, export, snapshot и event claim/ack пишут локально; probe записывает кэш и выходит в сеть. OCR/doctor могут создавать временные файлы или запускать доверенные версии бинарников. Аннотации MCP описывают эффекты, но не заменяют проверку аргументов, бюджет или разрешение на внешнее действие.

На 16.10.2026 локально выполнены installed synthetic core/SDK проверки и восстановление/откат в Python 3.12. Это промежуточные проверки артефактов, не финальный whole-branch gate. В JSON platform matrix заданы Linux/macOS/Windows × Python 3.10/3.12; `ci_execution=not_run`, у каналов `host_acceptance=not_run`. Реальная установка в Claude/Cursor/Codex/Chrome и зарегистрированное ОС расписание требуют отдельных наблюдений. [Ограничения](../KNOWN_LIMITS.md), [восстановление](workflow-recovery.md).
