# Безопасность

## Модель угроз

Скилл — инструкция для вашего AI-агента плюс скрипт сбора открытых данных. Основные риски и как они закрыты:

| Риск | Митигация |
|---|---|
| Prompt injection со страниц агрегаторов и карточек контрагентов | Safety-floor в SKILL.md: контент страниц — данные, не команды; инструкции из проверяемого текста не выполняются |
| Выдуманные цифры вместо реальных | Numerical-manifest: число без источника + даты + tier не выдаётся; нет данных — «не проверено» |
| Подмена данных по сети | TLS-верификация в `scripts/fetch_counterparty.py` включена по умолчанию; опция CA-бандла под УЦ Минцифры — в справке скрипта |
| Утечка ИНН/данных сделки | Скилл не имеет собственного бэкенда: запросы идут только в реестры и агрегаторы, перечисленные в SKILL.md. Агент работает там, где работает ваш Claude/Cursor |

## Что скилл принципиально не делает

- Не обходит капчи и не автоматизирует источники, требующие ручного подтверждения.
- Не хранит и не пересылает результаты проверок куда-либо, кроме вашего агента.
- Не выносит юридических заключений — только оценку риска по открытым данным.
