Проверка ИП по ИНН

ИП — другой объект проверки: публичной отчётности нет, адреса нет, зато есть статус самозанятого и внесудебное банкротство физлиц. По 12-значному ИНН скилл сам переключается на контур ИП — и не пытается выдать за факт то, что закрыто законом.

Композитный светофор ИП

  • Возраст и статус (ЕГРИП ✅) — действующий ли, когда зарегистрирован.
  • НПД-статус — самозанятый ли (npd.nalog.ru check-status, единственный официальный публичный API ФНС).
  • Спецрежим и численность — УСН/патент и ССЧ из «Прозрачного бизнеса» (поиск ИП идёт отдельным режимом search-ip).
  • МСП — в реестре ли; исключение из реестра = стоп-сигнал 🟡 минимум.
  • Дисквалификация — спецреестры/браузер.
  • ФССП — обязательно два поиска: ИП как юрлицо по ИНН и физлицо по ФИО + дата рождения + регион. Официального API ФССП больше нет — только браузер.
  • ЕФРСБ — включая внесудебное банкротство физлиц, которого нет в арбитражной картотеке.
  • Контракты ЕИС — выигранные закупки как сигнал «живой бизнес».

Самозанятый или ИП: почему это важно перед оплатой

Если контрагент работает как самозанятый (плательщик НПД), его чеки можно учитывать в расходах и не удерживать НДФЛ — но только если статус действующий на дату чека. Скилл проверяет это через официальный сервис ФНС check-status (схема по официальному описанию API; с не-РФ IP сервис недоступен — в этом случае честное «не проверено», а не выдуманный статус).

Принципиально недоступно по ИП (закрыто законом, не кодом)

  • Выручка и баланс — у ИП нет публичной отчётности; финансовый профиль кодом неприменим, ответ — «не проверено».
  • Налоговая задолженность — спецреестр ФНС публикует её только по юрлицам (ст. 102 НК РФ).
  • Адрес ИП — закрыт 152-ФЗ «О персональных данных»: сигналы «массовый адрес» и «недостоверность адреса» к ИП неприменимы, чеклист однодневки для ИП считается без них.
  • ОгрДоступ — краевой случай ограничения доступа к сведениям от ФНС: «не нашёлся» ≠ «не существует», помечается отдельно.

Как запустить

python3 scripts/fetch_counterparty.py <ИНН ИП> # поле "тип": "ип" — движок сам разводит по длине ИНН (10 знаков ООО, 12 — ИП)

В агенте: «проверь этого ИП по ИНН перед оплатой» — quick-scan с учётом ИП-контура соберётся сам.
