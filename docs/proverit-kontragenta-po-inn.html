Как проверить контрагента по ИНН бесплатно

Отгрузить в долг, внести предоплату, подписать договор на год — и через месяц узнать, что контрагент в банкротстве. Всё это было открыто ещё до сделки: в ЕГРЮЛ, ФССП, картотеке арбитража и ЕФРСБ. Проверка по ИНН сводит эти реестры в один светофор 🟢/🟡/🔴 за те минуты, что есть у собственника.

Быстрый путь: две минуты

  1. Поставьте скилл: npx skills add ilyautov/inn-check-ru (или ZIP с последнего релиза).
  2. Скажите агенту: «проверь поставщика по ИНН … перед предоплатой».
  3. Получите карточку: светофор, 1–2 причины, рекомендация (отсрочка / только предоплата / избегать), что проверено и что нет.

Без агента то же делает движок напрямую: python3 scripts/fetch_counterparty.py <ИНН> — один JSON по источникам ФНС.

Что проверяется: quick-scan против полного досье

Quick-scan (всегда первым) идёт только по deal-killer-сигналам — тем, что одни делают сделку опасной: ликвидация или реорганизация, банкротство, недостоверность сведений в ЕГРЮЛ, дисквалификация директора, санкционная сверка (офлайн, секунды), долги крупнее суммы сделки. Нашёлся хоть один — 🔴 и дальше можно не собирать: ~70% отсева происходит здесь.

Полное досье — по запросу «разверни карточку»: финансовый профиль кодом из строк ГИР БО, признаки однодневки и дробления, граф связей, суды и банкротства через браузерный слой, мониторинг изменений снимками.

Почему не просто один агрегатор

В живом тесте (15.06.2026) одна компания у пяти бесплатных агрегаторов дала число судебных дел от ~500 до ~1500 — а один подмешал чужие банкротные «намерения». Поэтому правило скилла: факт — это совпадение трёх и более источников; расхождение — флаг, а не повод выбрать красивую цифру. Каждая цифра в досье идёт с источником, датой и tier-маркером (✅/⚠️/❌).

Честные ограничения

  • Суды и банкротства — браузерный слой: голый скрипт за DDoS-Guard не проходит, официальный API ФССП отключён с 2022 года.
  • Учредители и аффилированность — через checko (бесплатный ключ) или браузер; рёбра графа помечены «⚠️ один источник, требует пересечения».
  • Пороги светофора — эвристика из методичек ФНС, открытая и настраиваемая; статистической калибровки по выборке пока нет.
  • Светофор — оценка для собственника, не приговор контрагенту и не юридическая гарантия. Для крупной сделки — рабочий лист для юриста.
