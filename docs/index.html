ПЕРЕД ПЕРВОЙ ПРОВЕРКОЙ

По делу.

Нужны платные API-ключи?+

Базовые источники можно запрашивать без ключей. Для автоматического графа связей нужен ключ Checko. Доступ к реестрам может зависеть от сети; отдельные источники требуют браузерной проверки.

Можно проверить ИП?+

Да. Для 12-значного ИНН предусмотрены отдельные проверки ИП, включая ЕГРИП и статус НПД. Закрытые сведения об ИП не восстанавливаются из предположений.

Кто увидит проверяемый ИНН?+

Если работаешь через AI-агента, ИНН попадает в контекст его провайдера. Источники и подключённые агрегаторы видят свои запросы, настроенный прокси видит проходящий через него трафик. Загруженные санкционные перечни сверяются локально. Подробнее о данных ↗

Можно проверить всю базу?+

Есть пакетная проверка списка контрагентов и сравнение сохранённых снимков. Для регулярного мониторинга нужно отдельно настроить расписание. Сам по себе лендинг проверки не запускает.

Светофор гарантирует безопасность сделки?+

Нет. Это оценка по доступным данным и выбранному профилю сделки. Отчёт помогает определить вопросы для проверки. Он не заменяет изучение договора, подтверждение исполнения и профессиональное заключение.
