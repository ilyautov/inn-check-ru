# inn-check-ru-mcp

MCP-сервер проверки российского контрагента по ИНН. Светофор риска по открытым
реестрам ФНС, финансы из ГИР БО, санкционные перечни РФМ, OFAC и ЕС. Пороги
и расчёты сделаны кодом, а не текстом модели. Источник, который не ответил,
помечается «не проверено» и не выдаётся за «чисто».

Это пакет-обёртка: весь код лежит в [`inn-check-ru`](https://pypi.org/project/inn-check-ru/),
здесь только точка входа, чтобы сервер запускался одной командой:

```bash
uvx inn-check-ru-mcp
```

Claude Code:

```bash
claude mcp add inn-check-ru -- uvx inn-check-ru-mcp
```

Переменные окружения, все необязательные:

- `CHECKO_API_KEY` нужен только для графа связей, без него эти инструменты
  отвечают «не проверено»;
- `INN_CHECK_PROXY` задаёт ваш собственный прокси с РФ-IP. Узел видит, какие
  ИНН вы проверяете, поэтому годится только своя нода.

Документация, ограничения и политика конфиденциальности:
https://github.com/ilyautov/inn-check-ru
