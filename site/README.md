# Исходники лендинга

Публичный сайт — `docs/` (GitHub Pages, `main:/docs`, домен в `docs/CNAME`).
Здесь только исходник интерактива: `main.ts` собирается в `docs/app.js`.

```bash
cd site
npm ci
npm run typecheck
npm run build        # -> ../docs/app.js
npm run dev          # http://127.0.0.1:4186, раздаёт ../docs
```

- `docs/index.html` — статический текст и первый пример для режима без JS; при
  правке первого сценария синхронизировать `index.html` и `main.ts`.
- `docs/style.css`, `docs/experience.css` — стили главной. `docs/styles.css` —
  стили тематических SEO-страниц, их не трогать.
- `docs/assets/` — иллюстрации WebP, знак, локальные шрифты с лицензиями,
  `og.jpg` (обложка для соцсетей, 1280×640).
- `docs/proof/` — записанный запуск CLI (28.09.2026, коммит b741b0a): JSON без
  служебного токена, локальных путей и ФИО, метаданные, скрипт повтора.

Три интерактивных сценария — учебные, не результаты движка. Реальный запуск —
только блок `#live-run` и `docs/proof/`; дату и цифры старого запуска не менять,
новый запуск — новые файлы с новым временем и SHA.
